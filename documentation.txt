DOCUMENTACIÓN DEL SISTEMA DE INVENTARIO (INVENTA_SYSTEM)
=============================================================

1. DESCRIPCIÓN DEL SISTEMA
-------------------------
El sistema INVENTA_SYSTEM es una aplicación web desarrollada en PHP que proporciona una plataforma para la gestión de inventario. El sistema implementa funcionalidades de autenticación de usuarios (registro, inicio de sesión y cierre de sesión) y módulos completos para la gestión de proveedores, productos, clientes, ventas y caja (facturación).

2. MÓDULOS DEL SISTEMA
---------------------

2.1. Módulo de Autenticación
    - Registro de usuarios nuevos
    - Inicio de sesión con validación de credenciales
    - Cierre de sesión seguro
    - Verificación de correos electrónicos duplicados
    - Encriptación de contraseñas con password_hash
    - Implementación en:
      - controlador: controller/HomeController.php
      - modelo: model/HomeModel.php
      - vistas: view/home/login.php, view/home/signup.php, view/home/logout.php

2.2. Módulo de Proveedores
    - Listado de proveedores con tabla dinámica (DataTables)
    - Funciones CRUD completas (Crear, Leer, Actualizar, Eliminar)
    - Gestión de información empresarial (NIT, dirección, teléfono)
    - Gestión de contactos directos
    - Implementación en:
      - controlador: controller/SupplierController.php
      - modelo: model/SupplierModel.php
      - vista: view/home/suppliers.php
      - JS cliente: asset/js/supplier.js

2.3. Módulo de Productos
    - Listado de productos con tabla dinámica (DataTables)
    - Funciones CRUD completas (Crear, Leer, Actualizar, Eliminar)
    - Relación con proveedores (select para proveedor)
    - Gestión de precios de entrada y venta, unidad y cantidad
    - Implementación en:
      - controlador: controller/ProductController.php
      - modelo: model/ProductModel.php
      - vista: view/home/products.php
      - JS cliente: asset/js/product.js

2.4. Módulo de Clientes (nuevo)
    - Listado de clientes con tabla dinámica (DataTables)
    - Funciones CRUD (Crear, Editar, Eliminar)
    - Campos: nombre, numero_documento, direccion, telefono, correo
    - Implementación en:
      - controlador: controller/CustomerController.php
      - modelo: model/CustomerModel.php
      - vista: view/home/customers.php
      - JS cliente: asset/js/customer.js

2.5. Módulo de Ventas (nuevo)
    - Listado de ventas con tabla dinámica
    - Eliminación de ventas
    - Tablas relacionadas: venta, venta_producto
    - Implementación en:
      - controlador: controller/SalesController.php
      - modelo: model/SalesModel.php
      - vistas: view/home/sales.php, view/home/Sales.php
      - JS cliente: asset/js/sales.js

2.6. Módulo Caja / Facturación (nuevo)
    - Generación de facturas / registro de ventas con detalle de productos
    - Transacción atómica al insertar venta y sus productos (uso de transacciones PDO)
    - Genera numero_venta, inserta venta en tabla venta y detalle en venta_producto
    - Implementación en:
      - controlador: controller/CashRegisterController.php
      - modelo: model/CashRegisterModel.php
      - vista: view/home/cashRegister.php
      - JS cliente: asset/js/cashRegister.js

2.7. Módulo Usuarios (nuevo / listado)
    - Listado de usuarios para seleccionar vendedor en caja
    - Implementación en:
      - controlador: controller/UserController.php
      - modelo: model/UserModel.php

2.8. Panel de Control y navegación
    - Vista principal con accesos al módulo de productos, proveedores, clientes y ventas
    - Implementación en:
      - vista: view/home/panelControl.php
      - cabecera y pie comunes: view/head/head.php, view/head/header.php, view/head/footer.php

3. REQUISITOS DEL SISTEMA
------------------------
- PHP 7.4 o superior (el SQL export indica PHP 8.x en entorno de producción)
- MySQL 5.7 o superior
- Servidor web (Apache/Nginx)
- Laragon o XAMPP como entorno de desarrollo

4. PASOS PARA DESPLEGAR EL PROYECTO
----------------------------------
(Se mantienen los pasos previos, asegurar importación de inventa_system.sql)

4.1. Instalación del Entorno de Desarrollo
    OPCIÓN A - Usando Laragon:
    1. Descargar Laragon de https://laragon.org/download/
    2. Ejecutar el instalador y seguir los pasos
    3. Instalar con la configuración predeterminada
    4. Verificar que Apache y MySQL estén funcionando (iconos en verde)

    OPCIÓN B - Usando XAMPP:
    1. Descargar XAMPP de https://www.apachefriends.org/
    2. Ejecutar el instalador
    3. Seleccionar como mínimo los componentes Apache y MySQL
    4. Completar la instalación y iniciar los servicios

4.2. Configuración del Proyecto
    Si se tiene el archivo comprimido:
    1. Descomprimir el archivo del proyecto
    2. Copiar la carpeta 'vanessa_peña_AA2_EV01' en:
       - Laragon: C:\laragon\www\
       - XAMPP: C:\xampp\htdocs\

    Si se clona desde Git:
    1. Abrir terminal en la carpeta www o htdocs
    2. Ejecutar: git clone [URL_DEL_REPOSITORIO]

4.3. Configuración de la Base de Datos
    1. Abrir el administrador de MySQL (phpMyAdmin)
    2. Crear una nueva base de datos llamada 'inventa_system'
    3. Importar el archivo SQL de la estructura de la base de datos (si está disponible)
    4. Verificar la configuración en config/db.php:
       - Host: localhost
       - Usuario: root
       - Contraseña: (en blanco por defecto)
       - Base de datos: inventa_system

4.4. Verificación de la Instalación
    1. Abrir el navegador
    2. Acceder a:
       - Laragon: http://localhost/vanessa_peña_AA2_EV01/view/home/panelControl.php
       - XAMPP: http://localhost/vanessa_peña_AA2_EV01/view/home/panelControl.php
    3. Debería aparecer la página de inicio de sesión

6. CONSIDERACIONES DE SEGURIDAD
------------------------------
- Las contraseñas se almacenan encriptadas con password_hash
- Sanitización básica de entradas (strip_tags, filter_var, htmlspecialchars)
- Uso de consultas preparadas PDO en la mayoría de consultas
- Manejo de sesiones para acceso a páginas protegidas
- Recomendaciones: revisar validación y sanitización completa en todos los endpoints que reciben JSON (ej. productos en caja) y manejar errores/estatus HTTP en respuestas AJAX
